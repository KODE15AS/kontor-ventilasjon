# nilan — hovedventilasjonsanlegget

Hovedaggregatet er av fabrikat **NILAN**. Målet er todelt:

1. **Operatørstøtte** for brukere/driftere.
2. **Agentstyring direkte over Modbus** — fysisk forbindelse fra raven til
   aggregatets styringsenhet.

Avklares (dokumentasjon lastes opp etter hvert):

- NILAN-modell og styringsenhet (CTS602 = Modbus RTU / CTS700 = Modbus TCP)
- Fysisk vei: USB-til-RS485-adapter, Modbus TCP-gateway eller annet
- Registerkart og trygge grenser for agent-skriving

Status: venter på dokumentasjon fra Jørn.
