# AGENTS.md — kontor-ventilasjon

## Slik jobber vi på RAVEN

Fasit er **RAVEN-normene** i `raven-platform/README.md` (seksjonen
«RAVEN-normer»): handover, cursor, kontoer, tbd, container, stack, lenker,
web-profil, bestilling, språk. Følg dem; ikke gjenta dem i kode eller docs.

## Denne tjenesten

kontor-ventilasjon er ett repo og én Docker-container på RAVEN (norm
«container»). Innhold, kjøre- og testkommandoer fylles inn etter hvert som
spesifikasjonen i `handover/HANDOVER.md` tar form.
